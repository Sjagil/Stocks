# Macro Engine Freeze Report

The definitive content-addressed freeze artifact is generated by:

```powershell
python .\main.py macro freeze
```

It hashes `main.py`, the macro and screener configurations, all macro modules,
and the modified screener and research-autopilot integration modules. The
artifact also records frozen dependency integrity, configuration hash, store
counts, data limitations and unchanged authority.

The marker is valid only when the artifact reports:

```text
MACRO_ENGINE_AND_ANALYST_TECHNICAL_FROZEN_GO
```

This is a technical research freeze. It is not financial-finalist approval and
does not grant shadow, paper or live authority.
